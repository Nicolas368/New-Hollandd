# Tratores New Holland

## Descrição

Este projeto consiste em uma página informativa sobre os tratores da New Holland,
apresentando informações sobre a história da marca, tecnologias utilizadas,
categorias de tratores e a importância da mecanização para o agronegócio.

O projeto foi desenvolvido como atividade acadêmica para demonstrar conhecimentos
de desenvolvimento web utilizando HTML5 e CSS3.

## Tema escolhido

Tratores New Holland e sua importância para a agricultura moderna.
